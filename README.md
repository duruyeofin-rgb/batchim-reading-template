# 꿈꾸는 받침 여행 (batchim-reading)

초등 저학년을 위한 **한글 받침 읽기·쓰기 학습 웹앱**입니다.

이 앱의 가장 중요한 목적은 아이들이 문제를 많이 푸는 것이 아니라, **아이 한 명 한 명의 받침 읽기 성장을 누적해서 기록하고, 교사가 그 기록을 보고 알맞은 피드백과 후속 지도를 할 수 있게 하는 것**입니다. 아이는 받침을 배우며 별을 모으고 자신이 고른 직업의 세계를 하나씩 열어 나의 꿈 장면을 완성합니다. 교사는 학급을 만들고, 학생마다 시간에 따른 변화와 다음에 도와줄 부분을 한눈에 봅니다.

- 학생 화면: `/` (태블릿 가로 화면 기준)
- 교사 화면: `/teacher`

> **선생님들께**: 이 저장소는 누구나 내려받아 **자기 Supabase에 연결해서** 쓰는 복사본입니다. 학생 기록은 그 선생님의 Supabase에만 저장됩니다. 설치 방법은 **[SETUP.md](SETUP.md)** 를 보세요. (가입은 Supabase와 Vercel, 두 곳이면 됩니다.)

> 학습이 먼저이고 게임 보상은 뒤에 옵니다. 별은 돈처럼 쓰는 것이 아니라 모으는 것이고, 정해진 조건이 채워지면 직업의 세계가 하나씩 열립니다.
>
> 이 앱은 학생을 자동으로 평가하지 않습니다. 흩어진 학습 기록에서 교사가 놓치기 쉬운 패턴(예: "최근 3회에서 ㄺ 받침 오류가 반복됨")을 보여 주는 도구이고, 판단은 교사가 합니다.

## 주요 기능

### 학생
- **학급 입장**: 선생님이 알려 준 6자리 숫자 코드(또는 QR)와 내 번호로 들어옵니다. 이름·이메일·비밀번호가 필요 없습니다.
  - **QR을 찍으면** 이 기기에 저장된 이전 학생으로 이어 가지 않고, **학급 코드(6자리 숫자) 입력 화면**부터 시작합니다. 학생이 코드를 누르고 확인한 뒤 자기 번호를 고르면 학습이 시작됩니다(코드는 자동으로 채워지지 않습니다).
  - 주소만 열면(QR 없이) 같은 기기에서 이전 학생으로 이어서 시작합니다. 다른 친구가 쓰려면 위쪽의 「친구 바꾸기」를 누릅니다.
- **남/여 캐릭터와 꿈 직업 고르기**: 직업 29개 중에서 고르고, 직업이 하는 일 설명을 읽어 줍니다. 꿈은 언제든 바꿀 수 있습니다.
- **받침 여행 지도**: 1부 8개 단원(홑받침, 소리는 같은 받침 묶음)과 2부 7개 단원(겹받침).
  - 소리를 듣고, 또는 그림을 보고 알맞은 낱말을 고르는 **단어 문제**와 문장 속 빈칸을 고르는 **문장 문제**가 있습니다.
  - 틀리면 어디가 틀렸는지 받침을 짚어 주고 정답 소리를 들려 줍니다.
  - 모든 낱말·문장을 소리 내어 읽어 줍니다(🔊).
- **겹받침(2부)**: 문제를 풀기 전에 **낱말 카드**로 글자·소리·뜻을 익히고, 문제에는 **뜻 한 줄**이 함께 나옵니다. 겹받침은 1학년이 배우는 대로 `많다, 끓다, 읊다`처럼 `~다` 꼴로 냅니다. 소리 나는 대로 쓴 글자(예: 젊다 → 점다)가 매력적인 오답으로 들어갑니다.
- **읽기 테스트**: 두루책방 책에서 발췌한 문장을 소리 내어 읽습니다. 음성 인식으로 판정하고, 3번 읽어도 통과하지 못하면 선생님 확인을 기다립니다.
- **꿈 상자(나의 꿈 세계)**: 별과 이야기 읽기로 직업의 세계가 하나씩 열립니다.
  - 내 모습 1 → 일하는 도구 3 → 일하는 곳 2, 정해진 차례대로 열립니다.
  - 열 때마다 초등 1학년이 읽을 수 있는 **직업 정보 한 문장**이 나옵니다(예: 헤드셋 → "관제탑과 이야기하며 안전하게 비행해요.").
  - 도구는 따로 놓이지 않고 캐릭터가 직접 들거나 쓴 모습으로 나타납니다. 모두 열면 나의 꿈 장면이 완성됩니다.
  - 열리는 조건: 별 5·15·30·50·80·120개, 4번째부터는 이야기 읽기 1·1·2권 통과.
- **나의 꿈 이야기**: 꿈 완성 화면 끝에서 "나는 ○○가 되어서 …" 한 문장을 직접 쓰고 저장합니다(120자 이내). 다시 열면 쓴 글이 그대로 보이고 고칠 수 있으며, 선생님만 읽을 수 있습니다. (표를 만들기 전에는 이 칸이 나타나지 않습니다.)

### 교사
- **아이디(별명) + 비밀번호**로 로그인합니다. 이메일을 받지 않습니다(같은 아이디가 있으면 다른 아이디를 쓰라고 안내).
- 학급 만들기(학생 수 1~30명), 6자리 학급 코드와 **QR 코드**(칠판에 띄우기).
- **받침 성장 기록** (학생을 누르면 맨 위에 나옵니다): 현재 상태와 한 줄 요약, 최근 변화(좋아진 부분 · 계속 어려워하는 부분 · 새롭게 나타난 어려움), 다음 지도 추천, 날짜별 그래프(단어·문장·전체·읽기), 받침별 변화, **교사 피드백 메모**.
- **학급 현황**: 「먼저 살펴볼 학생」, 지도 상태(✅ 안정 · 👀 관찰 · 🔔 교사 확인 · ⏳ 기록 모으는 중), 최근 학습, 필터(최근 학습·학습 없음·성장 중·반복 오류·읽기 확인, 받침, 단원), 현재 단원·정답률·읽기 테스트·확인 대기.
- **기록 초기화**: 한 학생만 하려면 현황표 그 학생 줄 맨 오른쪽의 「초기화」 단추(또는 학생 상세의 「이 학생 기록 초기화」), 학급 전체는 학급 화면 위쪽의 「학생 전체 기록 초기화」('초기화'라고 입력해야 진행). 지울 것을 고를 수 있고(문제 풀이 기록·진도, 별과 꿈 세계, 캐릭터와 직업, 나의 꿈 이야기, 교사 메모), 지운 기록은 되돌릴 수 없으니 신중히 눌러 주세요(백업 파일 내려받기는 없습니다). 학급 코드와 번호, QR은 그대로이고, 학생이 앱을 켜 둔 기기는 몇십 초 안에 처음 화면으로 돌아갑니다.
- **CSV**: 전체 문제 기록, 그리고 학생당 한 줄의 **성장 요약**(현재 단원, 상태, 정답률, 최근 3회 변화, 어려워하는 받침, 읽기 확인 필요 등. 이름은 없고 번호만).
- **확인 대기**: 읽기 테스트에서 3번 틀린 문장을 선생님이 보고 「통과」 또는 「넘어가기」를 눌러 줍니다. 학생 화면에 몇 초 안에 반영됩니다.
- 학생별 자세한 기록: 단원별 정답률, 틀린 문항, 문단 읽기 기록(인식된 글자 포함). 학급 전체의 자주 틀린 받침 TOP 5.
- **나의 꿈 이야기**: 학생 상세에서 학생이 꿈 완성 화면에 쓴 글을 읽고, 부적절한 글은 삭제할 수 있습니다.
- **직업·꿈 세계 보기**: 직업 29개의 요소와 직업 정보 문장, 열리는 조건을 한눈에 봅니다.

## 학습 구성

| 부 | 단원 | 내용 |
|---|---|---|
| 1부 | 1-1 ~ 1-8 | 받침은 달라도 소리는 같은 묶음(ㄱ·ㅋ·ㄲ → [ㄱ] 등). 도전 낱말 중심 |
| 2부 | 2-1 ~ 2-7 | 겹받침 ㄳ ㄵ / ㄶ / ㄼ ㄾ(★밟다 예외) / ㅀ / ㅄ / ㄺ / ㄻ ㄿ |

- 단어 문제 → 문장 문제 순서로 풀고, 80% 이상 처음에 맞히면 통과합니다. 첫 번째 시도에 맞힐 때마다 별 1개.
- 학습 내용은 [`src/data/curriculum.ts`](src/data/curriculum.ts)에 있습니다. (수업이 시작된 뒤에는 기존 항목의 **순서를 바꾸지 마세요.** 저장된 기록이 문항 번호와 이어집니다. 추가는 뒤에만.)

## 읽기 테스트 (두루책방)

- 1~6단계 책 17권(1단계 2권, 2·3·4단계 각 4권, 5단계 2권, 6단계 1권)에서 발췌한 문장을 읽습니다. 책은 [`src/data/dooru.ts`](src/data/dooru.ts)에 있고, 학생은 「① 책 읽으러 가기」로 두루책방 책을 열어 읽은 뒤 「② 소리 내어 읽기」를 합니다.
- **판정**: 틀리게 읽은 어절이 하나라도 있으면 통과가 아닙니다. 브라우저 음성 인식은 틀리게 읽어도 자주 쓰는 말로 고쳐 적는 경우가 있어서, 인식된 글자를 교사 화면에 그대로 남깁니다.
- **책 추가 방법**
  1. 두루책방에서 PDF를 받아 `content/dooru/`에 둡니다. (이 폴더의 PDF는 Git에 올라가지 않습니다.)
  2. 책 마지막 쪽에서 **CC BY 4.0 표시와 저작자**를 확인합니다. 책 번호(`dir`)는 두루책방 첫 화면의 단계별 목록에서 그 책을 여는 주소의 `Dir=숫자`입니다.
  3. 읽을 부분(앞부분 몇 문장)을 `DOORU_BOOKS`에 추가합니다. 글만 쓰고 삽화는 쓰지 않습니다.
  4. 외국 원작을 바탕으로 한 책이면 원작·원작자를 `origin`에 적습니다.

## 성장 기록 (교사용)

- 새로 저장하는 성장 데이터는 없습니다. 기존 문제 기록(`attempts`)의 첫 시도 여부, 정답 여부, 시각, 단원에서 **계산**합니다. 계산은 [`src/lib/growth.ts`](src/lib/growth.ts)에 모여 있고, 기준값(`GROWTH_RULES`)도 거기에서 고칩니다.
- 기록이 적으면 판단하지 않습니다(전체 첫 시도 12개 미만, 받침 묶음은 8개 미만이거나 한 번만 푼 경우).
- 지도 상태는 학생을 평가하는 등급이 아니라 **선생님이 먼저 살펴볼 곳**을 알려 주는 표시입니다. 읽기(음성 인식)는 "자동 인식에서 확인 필요"로만 다루고, 능력을 단정하지 않습니다.
- 「나의 꿈 이야기」는 새 표 `dream_wishes`에 저장합니다. 이 표는 `supabase/setup.sql`에 들어 있습니다(되돌리기: `drop table public.dream_wishes;`). 학생은 자기 글만, 교사는 자기 학급 글만 볼 수 있습니다.
- 교사 피드백 메모는 새 표 `teacher_notes`에 저장합니다. 이 표도 `supabase/setup.sql`에 들어 있습니다(되돌리기: `drop table public.teacher_notes;`). 실행하기 전에도 성장 화면은 그대로 동작하고 메모 칸에만 안내가 나옵니다.
- 점검: `npx tsx scripts/check.ts`가 기록 없음·1회뿐·상승·유지·하락·특정 받침 반복·단어는 되고 문장은 어려움·고쳐 푸는 학생·읽기 인식 실패 시나리오를 확인합니다.

## 개인정보

- 학생 이름·성별·음성 녹음은 **저장하지 않습니다.** 번호, 고른 캐릭터(남/여)와 직업, 학습 기록, 읽기 테스트에서 인식된 글자, 그리고 꿈 완성 화면에서 학생이 직접 쓴 한 문장(「나의 꿈 이야기」, 선생님만 볼 수 있음)만 저장합니다. 글쓰기 칸에는 이름을 쓰지 않도록 안내가 있습니다.
- 학생은 익명 로그인을 사용하고, 행 수준 보안(RLS)으로 자기 기록만 읽고 쓸 수 있습니다. 교사는 자기 학급만 봅니다.
- 학급 코드 없이는 학습 화면에 들어갈 수 없고, 검색에 나오지 않도록 `noindex`를 설정했습니다.
- 저장이 잠깐 실패하면 기기에 임시 보관했다가 연결이 돌아오면 다시 보냅니다.

## 기술

React 18 · Vite 5 · TypeScript · Tailwind CSS 3 · React Router 6 · Supabase(Postgres, 익명 로그인, RLS) · Web Speech API(소리 내어 읽기, 음성 인식) · Vercel

```
src/
  data/       학습 내용(curriculum), 읽기 책(dooru), 직업·꿈 세계(jobs*.json, dreamWorld), 낱말 뜻(meanings)
  lib/        퀴즈 만들기(quiz, spelling), 한글 처리(hangul), 읽기 판정(similarity), 소리(tts), 서버(api, queue)
  student/    학생 화면(지도, 단원, 퀴즈, 읽기 테스트, 꿈 상자)
  teacher/    교사 화면(로그인, 학급, 현황표, 직업 보기)
  components/ 공통 화면 조각, 캐릭터 장면
supabase/     setup.sql (처음 설치 때 한 번 붙여 넣는 전체 SQL), 나머지는 그 원본 조각
public/img    낱말 그림 · public/dream 직업 그림
scripts/      점검·그림 만들기 도구
```

## 시작하기

처음 쓰는 선생님은 **[SETUP.md](SETUP.md)** 를 따라 하세요. 화면 순서대로 설명합니다. 요약은 이렇습니다.

1. [supabase.com](https://supabase.com)에서 프로젝트를 만들고 **Anonymous sign-ins**를 켭니다. (Email은 켜고 **Confirm email은 끕니다**.)
2. **SQL Editor**에 [`supabase/setup.sql`](supabase/setup.sql)을 통째로 붙여 넣고 Run합니다. (여러 번 실행해도 안전합니다.)
3. **Project URL**과 **anon(publishable) key**를 복사합니다. `service_role`(secret) 키는 절대 쓰지 마세요.
4. `.env.example`을 `.env.local`로 복사해 두 값을 채우고 `npm install` → `npm run dev`로 내 컴퓨터에서 실행하거나, Vercel에 환경 변수 `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`를 넣고 배포합니다.
5. `npm run verify:install`로 설치와 접근 규칙(RLS)을 점검합니다.
6. `/teacher`에서 아이디와 비밀번호로 가입하고 학급을 만들면 6자리 코드와 QR이 나옵니다.

마이크(음성 인식)는 **HTTPS 또는 localhost**에서만 동작합니다. 다른 선생님도 가입시키되 학급은 초대한 분만 만들게 하고 싶다면 [`supabase/optional-teacher-invite.sql`](supabase/optional-teacher-invite.sql)의 안내를 보세요.

## 점검 명령

```bash
npm run build              # 타입 검사 + 빌드
npx tsx scripts/check.ts   # 낱말·문장·보기·피드백·읽기 판정·꿈 세계 자동 점검
```

`check.ts`는 성장 분석(기록 없음·1회뿐·상승·하락·특정 받침 반복·읽기 인식 실패 등 가짜 학생 9가지)도 확인합니다. 그 밖에 보기가 3개이고 서로 다른지, 정답 소리가 맞는지, 겹받침 낱말마다 뜻이 있는지, 직업마다 그림 파일이 모두 있는지, 직업 정보 문장이 너무 길지 않은지 등을 확인합니다.

## 내용 고치기

| 하고 싶은 일 | 고칠 곳 |
|---|---|
| 낱말·문장 바꾸기, 추가 | `src/data/curriculum.ts` (2부 낱말은 `HARD` 표) |
| 겹받침 낱말 뜻 한 줄 | `src/data/meanings.ts` |
| 직업 이름·설명, 그림 만드는 문장 | `src/data/jobs.json`, `src/data/jobs-extra.json` |
| 직업 정보 문장, 열리는 순서 | `src/data/jobs-world.json`, `src/data/dreamWorld.ts`의 `STEPS` |
| 읽기 테스트 책 | `src/data/dooru.ts` |
| 성장 판정 기준(오름·내림, 최근 학습 기준 등) | `src/lib/growth.ts`의 `GROWTH_RULES` |
| 낱말 그림(그림 문제) | `public/img/<문항번호>.webp` + `src/data/pics.ts`의 `PIC_IDS` |

그림 문제의 문항 번호는 `단원-w낱말순서(0부터)`입니다. 예) `1-3-w2`. `node scripts/process-pics.mjs <폴더>`로 512px webp로 변환합니다.

## 직업 그림 만들기 (선택, 유료)

직업 그림은 AI 이미지 생성으로 만들어 `public/dream/`에 넣었습니다(직업 29개 × 옷차림·도구·배경·도구 든 모습, 남/여). 새로 만들거나 고칠 때만 필요합니다.

1. OpenAI API 키를 만들어 `.env.local`에 `OPENAI_API_KEY=…` 한 줄로 넣습니다. (절대 Git이나 채팅에 올리지 마세요. 이미지당 요금이 붙습니다.)
2. `node scripts/gen-dream.mjs jobs <직업id>` (옷차림·도구·배경), `node scripts/gen-dream.mjs kit <직업id>` (도구 든 모습). 원본은 `art-work/dream/`에 저장됩니다(Git 제외).
3. `node scripts/process-dream.mjs`로 웹용 webp로 줄여 `public/dream/`에 넣습니다.
4. 끝나면 키를 폐기하세요. 사이트 자체는 이 키가 필요 없습니다.
